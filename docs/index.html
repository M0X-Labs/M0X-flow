m0x-flow ⚡

Run frontier-scale LLMs on the hardware you already own.

Triple engine architecture

One app. Three ways to run.

Switch modes at runtime — the sidecar dispatches each workload to the right engine.

⚡ Standard

llama.cpp / GGUF

Direct GPU/CPU KV-cache execution with native support for Windows, macOS (Metal), Linux, NVIDIA (CUDA), AMD (Vulkan), Intel (Vulkan/SYCL), and CPU.

★ Best cross-device compatibility

♻ AirLLM

Single-device layer swapping

Swaps transformer layers from disk into VRAM sequentially, executing 70B+ models on low-VRAM machines — one device at a time.

● Slow mode · layer-by-layer

◉ Exo Pods

P2P cluster inference

Ring Memory-Weighted Partitioning shards LLM layers across Macs, PCs, and GPUs on your local Wi-Fi network — with live tensor flow.

✕ Distributed mesh · LAN

Interface & tooling

Everything local, nothing noisy.

A monochromatic Obsidian interface engineered for clarity at a glance.

💬 Streaming Chat

Auto-scrolling transcript with server-sent event streaming, markdown bubbles, prompt history, and a stop-generation control.

📦 Model Hub

One-click Hugging Face downloads, local weight management, and disk-storage analytics with a total-capacity bar.

🕸 Pods Visualizer

Real-time canvas powered by @xyflow/react — cluster topology, per-device memory, ping latency, and active tensor flow.

📊 Hardware HUD

Live token-streaming throughput (tokens/sec) and VRAM monitoring overlay, always in the corner of the frame.

🛰 VPN / Tailscale ready

Manual IP peer override plus configurable UDP broadcast port — discover and join pods even across virtual networks.

🔌 Anthropic-compatible API

The sidecar exposes an Anthropic-compatible chat endpoint, so your existing tooling can talk to local models directly.

Three-tier system

Decoupled, sidecar-first.

The Rust shell owns the window; the Python sidecar owns the models.

Quick Start

Prerequisites: Node.js v18+, Rust v1.75+ with cargo, Python 3.10+.

# 1 · clone + frontend 
git clone https://github.com/M0X-Labs/M0X-flow.git
cd m0x-flow
npm install
# 2 · sidecar (Windows) 
cd backend-sidecar
python -m venv venv
.\venv\Scripts\activate
pip install -r requirements.txt
cd ..
# 2 · sidecar (macOS / Linux) 
cd backend-sidecar
python -m venv venv
source venv/bin/activate
pip install -r requirements.txt
cd ..
# 3 · run in dev mode 
npm run tauri dev
